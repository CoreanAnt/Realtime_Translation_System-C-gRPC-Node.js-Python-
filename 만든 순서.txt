6.
이제 파이썬으로 로컬 통역 프로젝트 만들기

가상환경 작성 (3.11 으로 프로젝트 환경 설정)
py -3.11 -m venv .venv
가상환경 실행
.\.venv\Scripts\activate

이후 python --version 버전확인
pip 업그레이드
python -m pip install --upgrade pip

가상환경에 CUDA 13.0 버전용 PyTorch 설치
pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu130

# SenseVoice(FunASR), Qwen(Transformers), 가속기(Accelerate)
pip install funasr modelscope transformers accelerate qwen_vl_utils

# gRPC 및 오디오 처리 도구
pip install grpcio grpcio-tools protobuf soundfile numpy

# TTS 라이브러리
pip install edge-tts

#프로토파일 넣고 나서 컴파일
python -m grpc_tools.protoc -I. --python_out=. --grpc_python_out=. Trans.proto

#이후 코드 짜서
python server.py

Grpc.Net.Client
Grpc.Tools

<ItemGroup>
  <Protobuf Include="Protos\Trans.proto" GrpcServices="Client" />
</ItemGroup>
